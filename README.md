# 🌟 Mino: Word Adventure

A fun, interactive, ad-free and privacy-first English word puzzle and literacy game designed for early learners (ages 4–7).

## ✨ Key Features
- 🐾 **30 3D Animals & 🍓 20 3D Fruits**: Lovable 3D Pixar-style character stickers for every word.
- 🦊 **Mino the Companion**: Friendly animated mascot guiding kids with joyful voice narration.
- 🧩 **Interactive Gameplay**: Drag-and-drop letter builder, listening challenges, and picture-matching.
- 🗺️ **Journey & Chapters**: Progressive chapter map with rewards and celebration effects.
- 🛡️ **Parent Center & Privacy**: Screen-time break reminders, daily word goals, and 100% offline local storage.
